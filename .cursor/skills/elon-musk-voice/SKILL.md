# Voix — registre mission + technique (compte 3xrep)

Un geste : **brouillon** d’un post (ou d’une réponse) pour le compte marque. Pas un personnage. Pas Elon Musk.

Arbre et portes : [`.cursor/skills/README.md`](../README.md). Les lire **avant**. Cadence / poster vs répondre → [`founder-x-growth`](../founder-x-growth/SKILL.md). Réponse qui touche → [`x-replies-that-hit`](../x-replies-that-hit/SKILL.md).

## Ce que c’est

Le **registre** : phrases courtes. Mission + technique. Punch. Une idée par post.

Ce n’est **pas** :

- Se faire passer pour Elon Musk (nom, bio, « as Elon », « going to Mars », Grok, Tesla, xAI).
- Un cosplay, une imitation, un deepfake, une signature volée.
- Le compte d’une personne. C’est **3xrep**, le produit.

## Avant d’écrire

1. Portes du [README](../README.md) : brouillon jusqu’au go ; pas de message privé ; marque seulement ; 129 $ / org / mois ; appel doux `https://3xrep.com/install`.
2. Contexte **défaut** : `README.md` + accueil + `/install`. Pas le dépôt entier. Recherche web seulement si le sujet vit (actu / outil / concurrent).
3. Affirmation douteuse → alors seulement ouvrir la source dans le repo, corriger, ne pas élargir.

## Recette

1. **Une idée.** Si tu en as deux, deux posts. Pas un fil sauf si chaque ligne tient seule.
2. **Première ligne = le post.** Elle doit se comprendre sans la suite. Accroche = fait ou tension, pas « Excited to announce ».
3. **Phrases courtes.** Point. Sujet + verbe. Couper les adverbes marketing (*powerful*, *seamless*, *unlock*, *game-changer*).
4. **Mission + technique.** Pourquoi ça existe (le fichier client ment) **et** comment (une URL dans l’agent, à côté du CRM, un verdict — pas un onglet HubSpot). L’un sans l’autre = pub ou tutoriel. Les deux.
5. **Punch.** La dernière ligne serre. Pas un emoji. Pas un hashtag. Pas « Thoughts? ».
6. **Preuve tenue.** Chaque fait produit a une source dans README / home / install. Pas de client inventé. Pas de pourcentage de signatures.
7. **Appel.** Souvent aucun. Si le post l’a mérité : `https://3xrep.com/install` une fois, sans « book a demo ».

## Voix — faire / ne pas faire

| Faire | Ne pas faire |
| --- | --- |
| « Your CRM is green because someone ticked a box. » | « We’re thrilled to launch our AI-powered VP. » |
| « Gong records the call. We don’t join it. » | « As Elon would say… » / « Let’s make sales multiplanetary. » |
| « $129 / month. The org. Not a seat. » | 99 €. « Starting at ». Deux prix. |
| « This stage is illegal. Nobody who signs is on the record. » | « You’ll close 30% more. » |
| Nous / 3xrep / l’agent | Je (fondateur). Édouard. Tiem. Uptoo. OC. |

Contractions : oui. Minuscules stylisées : non (ça imite une personne). Fautes exprès : non. Fil « 1/17 » : non.
