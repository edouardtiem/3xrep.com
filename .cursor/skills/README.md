## Contexte marketing — défaut

Ouvrir **seulement** :

1. [`README.md`](../../README.md) à la racine
2. Accueil : [`src/app/page.tsx`](../../src/app/page.tsx) — ou [https://3xrep.com](https://3xrep.com)
3. Install : [`src/app/install/page.tsx`](../../src/app/install/page.tsx) — ou [https://3xrep.com/install](https://3xrep.com/install)

Ne pas ouvrir le reste du dépôt par défaut. Pas le cerveau, pas le registre, pas le code Stripe, pas les sessions.

**Repo plus profond** seulement si une affirmation produit a l’air fausse (prix, enregistrement, écriture dans leur fichier client, pourcentage de signatures). Alors ouvrir la source, corriger le brouillon, ne pas élargir la lecture.

**Recherche web** seulement si le sujet **vit** (actu, outil, concurrent nommé aujourd’hui). Sinon : skip. La voix et la cadence n’ont pas besoin d’un tour de web.

## Portes — toutes les recettes

- **Brouillons seulement** jusqu’à : compte X marque 3xrep **et** lien d’install qui encaisse **et** **go explicite**. Sans les trois : le texte reste un brouillon. Ne pas poster. Ne pas programmer. Ne pas allumer de routine live.
- **Jamais de message privé automatique.** Jamais de message privé « pour pousser l’install ».
- **Marque seulement.** Compte 3xrep. Pas Édouard. Pas Tiem. Pas un visage fondateur. Pas un réseau.
- **Appel doux** → [https://3xrep.com/install](https://3xrep.com/install). Pas à chaque post. Pas « book a demo ». Pas Calendly.
- **Prix live :** **129 dollars / organisation / mois** (pas 99 euros). Copy site : *From $129/month. For the entire organization.* Devise locale au checkout, oui. Deux paliers, non.
- **Anglais** sur X (le site public est anglais).

## Secret — cold / online

Première organisation = inconnu sur le web. **Ne jamais nommer** le réseau de construction : Uptoo, OC, amis, un intro chaud, un nom de builder. L’acheteur froid ne doit pas pouvoir remonter.
