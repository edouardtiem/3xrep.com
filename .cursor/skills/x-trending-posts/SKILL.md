# Posts tendance. 1 to 2 originaux / jour

Choisir un sujet **vivant** collé au lexique 3xrep. Rédiger **1**, parfois **2**, posts originaux. Un fil compte pour **un** original. **Max 1 fil / jour.**

Pas un appât viral. Pas une usine. Pas une réponse (ça, c’est `x-replies-that-hit`).

**Ouvrir, ne pas recopier :** `x-language-radar` (mots vivants), `elon-musk-voice` (densité), `founder-x-growth` (gates, accroche, preuve, lien doux).

## Règles partagées

Détail : [README](../README.md). Tiennent ici :

- Contexte : README + home + `/install`. Plus profond seulement si une claim est douteuse.
- Web seulement si le sujet est vivant. Sinon skip.
- Brouillons jusqu’à compte X utilisable + org payante `/install` + go explicite. Pas de message privé auto. Compte fondateur (`@Edd08x` / Ed. / run 3xrep). **Je vs 3xrep**. **Mode A** (VP Sales agent = the future, org, pas sièges / cours / enregistreur) ou **Mode B** (couche d’intelligence sur tout le CRM, dans Claude / MCP). Jargon pipe = avancé, pas défaut. Copy X : point, virgule, phrases séparées. Pas —, pas –, pas `--`. Lien doux `https://3xrep.com/install`. Prix **$129 / org / mois**.
- Secret : cold / online. Jamais Uptoo, OC, amis comme builder ou réseau. Pas le nom légal complet dans chaque post.
- API X : annoncer le coût avant un appel cher. Web public + lectures cheap d’abord.

## Lexique (filtre, pas une wishlist)

Un trend compte **seulement** s’il touche un de ces fils :

ai agents · sales · outbound / inbound · revenue · gong · mcp · vp sales · discovery · Claude / ChatGPT / Notion MCP · CRM agents · AI SDR · revenue ops

Surprise OK s’il y a une **preuve** (phrase + URL) et un Mode A ou B **vrai**. Pas de mot collé après coup.

3xrep **n’est pas** un AI SDR, pas un rédacteur d’outbound, pas un Gong. On **surfe** le mot. On ne **devient** pas le mot.

## 1. Choisir le sujet

Ordre : lexique d’abord, trend ensuite. Jamais l’inverse.

1. **Vivant ?** Actu, outil, concurrent, mot de la semaine. Web public. X cheap : `get_trends_by_woeid` (monde `1`, US `23424977`), `search_news`, timeline courte. Archive / `search_posts_all` = cher → annoncer le coût, attendre ([README](../README.md) § API X).
2. **Adjacent ?** Les trois, sinon skip :
   - Le mot est dans le lexique (ou preuve qu’il y est collé).
   - Une phrase **Mode A** ou **Mode B** est vraie sans mentir.
   - Pas sport, célébrité, culture war, routine, crypto pump.
3. **Langue.** Sujet vivant → ouvrir `x-language-radar`. Prendre les mots qui marchent. **Pas** d’edit site.
4. Rien d’adjacent aujourd’hui → **skip ce skill**. Un post evergreen, c’est `founder-x-growth`, pas un bait.

Oui : news MCP / Claude → Mode B. Hype AI SDR → Mode A (*the VP Sales agent is the future*, pas *we are your AI SDR*). Gong / recorders → Mode A (*not a recorder*), **jamais** « we replace Gong ».

Non : #1 mondial hors lexique. « AI took my job » sans fichier client. Un mème, puis 3xrep en dernière ligne.

## 2. Un post ou un fil

Défaut : **un** post. Un punch. Stop.

Fil (**reply to own**, 2 to 4 tweets, **max 1 / jour**) seulement si chaque tweet apporte un **fait neuf** et que ça ne tient pas en un post. Ex. Mode B : où ça vit → une URL MCP → pas un onglet.

| Fil | Tuer le fil |
| --- | --- |
| 2 to 4. Reply to own. Chaque ligne tient seule. | « thread 🧵 ». 1/17. Tweet de padding (*here’s why*, *let me explain*). Mix A+B. 3xrep nommé deux fois. |

Deux originaux le même jour : **deux sujets** adjacents, deux Mode. Pas le même take recoupé. Un fil + un post = déjà 2. Pas un troisième.

## 3. Mode A ou Mode B

**Un** par post (ou par fil). Pas les deux.

| Sujet | Mode |
| --- | --- |
| Ce que ça doit être : VP, org, pas sièges, pas un cours, pas un enregistreur | **A** |
| Où ça vit : Claude / ChatGPT / Cursor / Notion, MCP à côté du CRM, pas un onglet | **B** |
| Les deux collent | En choisir **un**. L’autre = un autre jour |

**Avancé, pas défaut :** *Recording isn’t a verdict.* / *A green stage without a quote is a claim.* / *3xrep won’t fill that gap.* Seulement si le trend parle déjà ce langage.

## 4. Craft (checklist)

Avant d’écrire : ouvrir `founder-x-growth` (gates, 8 mots, preuve, lien) + `elon-musk-voice` (couper, punch). Radar déjà ouvert si le mot bouge.

- **Accroche.** 8 premiers mots = le trend + Mode A ou B. Pas « Unpopular opinion ». Pas stage / quote / gap en ouverture.
- **Nommer 3xrep ou take-only.** Take-only si le trend est la catégorie (AI SDR, Gong, MCP) et que le punch tient sans marque, sans « I built », sans lien. **3xrep** si on dit un mécanisme qu’on ship, le prix, ou *I built*. Dans un fil : le nom **une** fois, pas à chaque tweet. Lien `https://3xrep.com/install` **une** fois, **après** une preuve, jamais sur un take-only, jamais en ouverture.
- **Je vs 3xrep.** I / me = Ed. (construire, livrer, prix, avis). Geste produit = **3xrep** ou un fait sans pronom. Pas « he ». Pas *Gong records. I don’t join it.*
- **Phrases.** Courtes. Point, virgule, phrases séparées. Relire : zéro —, zéro –, zéro `--`.
- **Punch.** Dernière ligne porte seule. Puis silence.
- **Anti-sosie.** `elon-musk-voice`. Un oui → jeter.

## 5. Anti-patterns (un oui = jeter)

- Appât viral hors lexique, 3xrep collé à la fin.
- Jargon de liste d’affaires en ouverture : stage / quote / fill the gap / this stage is a lie.
- « We replace Gong ». Gong-killer. Pourcentage de signatures.
- Calendly, démo, « hop on a call », message privé.
- Fil rempli : 🧵, numéros, tweet sans fait.
- Mode A **et** Mode B dans le même original.
- « He » pour l’agent. I pour un geste produit.
- 99 €. Par siège. Nommer Uptoo, OC, amis. Nom légal complet.

## 6. Prêt à poster (succès)

Draft **prêt** seulement si tout est vrai :

1. Les trois gates (compte `@Edd08x` utilisable, org payante `/install`, go explicite). Sinon : **draft seulement**.
2. Sujet adjacent + preuve (phrase + URL).
3. Un Mode. Une forme (post | fil 2 to 4). Take-only **ou** 3xrep, tranché.
4. Anglais. Zéro tiret long / moyen / `--`. Accroche 8 mots. Punch seul.
5. Aucun anti-pattern. Anti-sosie : aucun oui.
6. Lien doux : zéro, ou une fois après preuve.

Sans les trois gates : on rend le draft. On ne poste pas.
