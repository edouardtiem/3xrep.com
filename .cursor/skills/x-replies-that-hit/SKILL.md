Une réponse. Ironie **légère**. Éloge **précis** si c’est vraiment bien. Idée **Mode A** ou **Mode B**.

**Mention 3xrep : environ 1 sur 4 ou 5** (20 to 25 %). Le reste : avis utile seulement. Pas de nom produit. Pas de « I built ». Pas de lien install.

Le locuteur : compte **`@Edd08x`**, Ed., bio **run 3xrep**. Pas un compte marque anonyme. **Je vs 3xrep** si on nomme le produit. Pas de I forcé. Pas de « he ».

Posts originaux : `founder-x-growth` + `elon-musk-voice`.

## Forme

| Beat | Oui | Non |
| --- | --- | --- |
| **Ironie** | Another recorder. Still no VP in the agent. | « This is so dumb. » Ratio, pile-on, humiliation |
| **Éloge** | Nommer **exactement** ce qui est cool, une phrase | « Love this! » / « Fire 🔥 » / éloge pour exister dans le fil |
| **3xrep** | **~1 sur 4 ou 5.** Une phrase org légère. | Nommer 3xrep / « I built » sous chaque parent. Feature list, prix + spec + lien |
| **Longueur** | 1 to 3 phrases. Souvent 1 or 2. | Essai. « Actually, » + cinq paragraphes |

Les deux beats (ironie **et** éloge) dans la même réponse : rarement. Choisir.

**Défaut (3 ou 4 réponses sur 5) :** idée Mode A ou B, **sans** 3xrep.

- Mode A : *The VP Sales agent is the future. Not seats. Not a course. Not a recorder.*
- Mode B : *An intelligence layer on top of your whole CRM. Inside the Claude agent you already use.*

**Case 20 to 25 % (une phrase org, pas les trois) :**

- Mode A : *I built 3xrep. The VP Sales agent for the whole org.*
- Mode B : *3xrep is an intelligence layer on top of your CRM. Inside Claude.*
- **Avancé, pas défaut :** *3xrep won’t fill that gap.* Seulement si le fil parle déjà stage / quote.

Puis **stop**. Lien `https://3xrep.com/install` **seulement** si le parent a **demandé** un outil. Pas Calendly. Pas de message privé. Pas sous chaque inconnu.

Préférer les fils à **grande portée**. Pas le même texte collé sous plusieurs parents.

- Fil à portée nulle si on a un parent plus lu. On préfère la grande portée.
- On n’a pas lu le parent. Aller le chercher (lecture cheap) ou skip.

## Étapes

1. **Répondre du tout ?** Non → une ligne pourquoi, on passe. Préférer **grande portée**.
2. **Beat.** Ironie légère **ou** éloge précis. L’éloge seulement si tu peux pointer un geste, une phrase, un mécanisme. Pas l’auteur.
3. **Phrase org.** Compter la série. Viser ~1 mention 3xrep sur 4 ou 5. Défaut : zéro (pas de 3xrep, pas de « I built », pas de lien). Case 20 to 25 % : **une** phrase légère. Jamais deux. I seulement si c’est Ed. qui construit / prix / avis. Produit nommé → **3xrep**. Pas de « he ». Pas de jargon pipe en réponse froide.
4. **Sarcasme.** Relire à voix haute. Si ça sonne cruel sans fait : couper. L’ironie vise **le fichier client qui ment**, pas la personne.
5. **Registre.** Phrases courtes (`elon-musk-voice`). Pas de cosplay Elon. Pas de tiret long. Pas le même draft collé deux fois.
