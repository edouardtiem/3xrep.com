# Réponses qui touchent — compte 3xrep

Un geste : **brouillon d’une réponse** sous le post de quelqu’un d’autre. Ironie légère si le propos est mou. Éloge **précis** si c’est vraiment bien. Une phrase d’organisation sur 3xrep, pas un argumentaire.

Arbre et portes : [`.cursor/skills/README.md`](../README.md). Les lire **avant**. Faut-il répondre ? → [`founder-x-growth`](../founder-x-growth/SKILL.md). Registre des phrases → [`elon-musk-voice`](../elon-musk-voice/SKILL.md).

## Avant

1. Portes : brouillon jusqu’au go. **Jamais de message privé.** Marque seulement. 129 $ / org / mois. Lien [https://3xrep.com/install](https://3xrep.com/install) : rarement, presque jamais dans une réponse.
2. Contexte **défaut** : `README.md` + accueil + `/install`. Web seulement si le post parle d’un outil / concurrent / actu qui vit. Repo plus profond seulement si notre phrase produit cloche.
3. Lire **le post cible**. Répondre au point. Pas à un mot-clé. Pas à l’auteur.

## Recette

1. **Décider** — une case :

   | Case | Test | On écrit |
   | --- | --- | --- |
   | **Skip** | Rien à ajouter, ou on ne ferait que se coller | Une ligne. Pas de réponse. |
   | **Couper** | Le propos est mou / faux sur le métier (CRM vert, « l’IA close », enregistrement = vérité) | Ironie **légère**, une correction nette |
   | **Éloge** | Un vrai truc cool (refus d’inventer, preuve avant étape, on n’enregistre pas) | Nommer **exactement** ce qui est bien. Pas « 🔥 » |
   | **Ajouter** | Le fil est juste, il manque le fait 3xrep | Une phrase d’org, collée au fil, pas un pitch |

   En doute : **skip**.

2. **Ironie légère, pas la méchanceté.** On pique l’idée (la case cochée, l’étape fantôme). On ne pique pas la personne, le corps, le compte petit pour le sport. Pas de pile-on. Pas de « ratio ». Pas de sarcasme gratuit si le post est déjà correct.

3. **Éloge précis.** « La partie “ne pas inventer le champ manquant” — c’est tout le produit. » Pas « love this » / « so important ». Si ce n’est pas vraiment cool : skip, ne pas flatter pour exister.

4. **Une phrase d’organisation.** Maximum **une**. Elle dit ce qu’est 3xrep sans vendre :

   - Tenues : VP dans l’agent qui ne croit pas le CRM ; on n’entre pas dans l’appel ; 129 $ l’org pas le siège ; on nomme l’étape qui ment.
   - Interdites : démo, Calendly, « we help sales teams », « book a call », pourcentage, « on remplace Gong », 99 €, handle perso.

   Beaucoup de réponses : **zéro** phrase 3xrep. Le fait métier suffit. Le lien install : seulement si on le demande dans le fil.

5. **Longueur.** 1–4 phrases. Première ligne = la réponse. Pas un fil. Pas de hashtag. Pas de @ de l’auteur en plus (X le fait déjà).

6. **Contrôle impersonation.** Même registre court que la voix marque. Pas d’Elon la personne.

## Faire / ne pas faire

| Faire | Ne pas faire |
| --- | --- |
| « The CRM says Negotiation. Nobody who signs is on the record. Cute. » | « This is the dumbest take on the timeline. » |
| « Gong records. That’s a choice. The missing field still isn’t a fact. » | « Check out our AI platform 👇 » |
| « 3xrep is the VP in the agent that says which stage is a lie. » (une fois, si ça colle) | Coller la même phrase sous chaque post « sales AI » |
| Skip | Répondre pour être visible |
