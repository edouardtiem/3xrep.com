# Croissance X. Patterns fondateur, compte fondateur

Comment le compte **fondateur** grandit vraiment : rythme, accroche, répondre plus que poster, preuve, lien doux. `@Edd08x`, Ed., bio **run 3xrep**. Pas un compte marque sans visage. Pas un ghostwriter qui « fait l’Elon ». **Je vs 3xrep**. Chaque post : **Mode A** ou **Mode B** (l’idée, pas une maxime). Pas de I forcé. Pas de « he ».

Registre des posts : `elon-musk-voice`. Réponses : `x-replies-that-hit`.

## Mix

| Levier | Règle |
| --- | --- |
| **Répondre vs poster** | Petit compte : **plus de réponses que de posts**. Viser ~5 réponses utiles pour 1 post. Un post sans réponses autour = un tract. **3xrep / « I built » dans ~1 réponse sur 5.** Les autres : avis de terrain, sans nom produit. Préférer les fils à grande portée. Pas le même texte collé. |
| **Cadence** | Tenable. 1 post original / jour **max** une fois le go. Mieux : 3 to 5 / semaine + réponses le jour même. Silence 10 jours puis rafale : interdit. |
| **Accroche** | Les 8 premiers mots = un fait (stage / close date / owner / call / pipe) **ou** Mode A (org, pas sièges) / Mode B (dans Claude, à côté du fichier client). Pas « Unpopular opinion ». Pas une maxime (vanity, verdict, race, scarce, fiction). |
| **Preuve** | Un fait nommé. Mode A : org, pas sièges, pas un cours, pas un enregistreur. Mode B : une URL MCP à côté du connecteur, pas un onglet. « I built » seulement si ça sert, pas sous chaque post. Pas « we’re live », pas « building in public » vide. Pas « I built 3xrep so… ». |
| **Lien doux** | Posts : `https://3xrep.com/install` **une** fois, **après** la preuve. Pas chaque post. Pas en première ligne. Réponses : `https://www.3xrep.com/install` seulement si le parent a demandé un outil. |

## Accroches qui tiennent (3xrep)

Une idée. Une ou deux phrases. Comme la Session, pas une affiche.

**Mode A (idée) :** *I’m not selling seats.* / *Not a course. Not a recorder.* / *I price 3xrep $129 / org / month.* Pas : *The VP Sales agent is the future* en ouverture de chaque post.

**Mode B (idée) :** *3xrep runs inside the Claude agent you already use.* / *One MCP URL next to the CRM connector.* / *Not another CRM tab.*

**Terrain (souvent mieux qu’un slogan) :** *This stage is illegal.* / *That date is a claim, not a fact.* / *I won't fill the gap.* / *If the stage still says Negotiation and nobody who signs is named, the stage is fake.* / *Opens don't close deals. Did anyone actually call back?*

Non : *AI will replace your VP.* / *Stop doing sales training.* / *We replace Gong.* / *Sign 30% more.* / *He doesn’t join the call.* / *Opens are vanity.* / *The callback is the verdict.* / *Recording isn't a verdict.* / *I built 3xrep so…*

Wedge : founder déjà dans l’agent (Claude, Cursor, ChatGPT) + un fichier client. Pas le commercial qui ne sort pas de HubSpot.

## Étapes

1. **État.** Zéro post / quelques posts / déjà une voix. Une ligne.
2. **Mix de la semaine.** Nombre de posts originaux + nombre de réponses. Noms de fils où répondre (produit, pas culture war).
3. **Chaque post prévu :** mode (A/B) · accroche (8 mots, un fait) · preuve (oui/non, laquelle) · lien doux (oui/non). Si ni Mode A ni Mode B : tuer le post. Si triade maxime → jugement → produit : tuer.
4. **Rédiger** via `elon-musk-voice` (posts) et `x-replies-that-hit` (réponses). Posts : Mode A ou B, 3xrep si ça sert. Réponses : ~1 sur 5 nomme 3xrep. Pas une phrase org sous chaque parent.
5. **Calendrier** en anglais, dates, **statut draft** tant que les gates ne sont pas verts.
