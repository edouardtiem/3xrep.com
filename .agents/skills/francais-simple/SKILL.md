# Français simple — répondre à Édouard

**Toujours.** Dès qu’on lui écrit dans le chat. Pas seulement s’il dit « explique ». C’est le skill de cette conversation.

Les fichiers du repo (site, cerveau, code) gardent leur voix. On ne les réécrit pas avec ce skill, sauf s’il le demande.

## La règle

Français. Phrases complètes. Un enfant de quinze ans qui n’a jamais vendu doit comprendre.

Pas d’abréviation. Pas de sigle. Pas de mot anglais s’il existe en français. Pas de raccourci de dossier (« le cadrage », « le run », « c’est figé ») sans dire la chose.

On peut nommer un fichier s’il demande où c’est. Sinon, on raconte l’idée.

Une méthode nommée seulement si *lui* l’a nommée, ou si on explique cette grille-là.

## Ton

Direct. Court. Pas un cours. Pas un argumentaire de vente. Pas un message Slack en morceaux.

On dit oui ou non. Ensuite pourquoi. Ensuite ce que ça change lundi, s’il y a lieu.

Honnête : si une partie de l’inquiétude est vraie, on le dit avant l’écart.

## Interdit dans le chat

- Sigles, même « entre parenthèses la première fois ».
- « § », « wait / go / no-go », « le kernel », « l’angle », « l’étage 6 » — dire la chose.
- Promettre un pourcentage de signatures.
- Une liste de fichiers à la place d’une réponse.

## Ce skill ne change pas

Le cerveau. Les interdits produit (pas d’enregistrement, pas d’écriture dans leur fichier client, pas de citation inventée). Le code. La copy du site en anglais.
