# Inventaire — 3xrep

Figé. 30 août 2026. Auteur : Édouard Tiem (recherche catalogues, versé dans le moule).

Ce qu’on **produit**. Pas un programme qu’on ferme. [cadrage.md](cadrage.md) gagne. [template-parcours.md](template-parcours.md) est le moule. [roadmap.md](roadmap.md) item 1.

On n’ouvre **aucun** parcours hors le test 1 tant que la semaine 2 n’a pas dit oui.

## Ce que c’est

Une liste de **pièces** : étape × cycle (court / long) × situation déjà mal partie.

Un item ici = un **parcours** (famille). L’IA (point 3) multiplie les **cas**. La difficulté (point 2) = des **copies**, pas des variantes, pas un parcours de plus.

Google cherche le **cas** (`titre_google`). Le HUD montre le **deal**. Le piège se découvre.

## Filtre — d’où ça vient, ce qu’on jette

Catalogues lus (cursus, modules, certifs). On en garde les **situations** que le commercial reconnaît. On jette le reste.

| On a lu | On garde | On jette |
| --- | --- | --- |
| Uptoo (fondamentaux, phoning, découverte BEBEDC, closing, négo, LinkedIn, AM/KAM) | Appel, barrage, découverte, trop cher, remise, contreparties | Management, IA outils, motivation, tournées, vente indirecte, CPF |
| Cegos (7 réflexes, SIGNER, vente AGILE, PSAI / SONCASE / CRAC) | Cibler, contacter, connaître, CRACquer, conclure, lâcher / contreparties | Parcours client LMS, fidéliser comme module 7, visio comme produit |

| Force Management (Command of the Message / Sale, Value Negotiation, MEDDPICC) | Current state → conséquences, required capabilities, value vs feature | Messaging GTM, train-the-trainer |

**Même famille, pas un parcours de plus** (déjà tranché) : champion gentil zéro pouvoir = Call avec l’ops. L’ops qui cache, le process politique, tu arrives tard = **difficulté** (copies), pas un `id` nouveau.

## Contrat d’une ligne

Chaque parcours ici déclare le minimum du moule. `quete` = A+B partout. Pas de QCM, pas de CYOA 2 min, pas de meeting.

`ouvrir` = **non**, sauf le test 1.

## Compte

**29 parcours** dans l’usine. **1 ouvert** : `daf-pas-dans-la-piece`.

Les cas (graines, puis générateur) vivent **dans** un `id`. Pas 29 × difficulté × N comme catalogue LMS : 29 familles. Des copies. Des deals qui changent.

## Ce que ça n’est pas

- Semaine 1 prospection → semaine 2 découverte.
- Un module par méthode (pas de parcours MEDDIC).
- Hyperbound (la bouche). Mindtickle (la certif).
- Une liste à « terminer ».
- L’ouverture des 28 autres. Le test, c’est Call avec l’ops. Semaine 2, elles reviennent toutes seules. Oui = on coule la suite. Non = stop.
