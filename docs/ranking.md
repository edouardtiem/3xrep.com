## Figé — page ≠ tableau, étoile ≠ challenge

GitHub ne classe pas les gens. Trois couches, on copie ça.

| Couche | GitHub | 3xrep |
| --- | --- | --- |
| Exister | `github.com/toi`, même à 0 étoile | `3xrep.com/<pseudo>` dès qu’une prise est **publique** |
| Monter (combat / PLG) | — | Deux gens ont essayé de casser la lecture avec une pièce, elle tient → tableau **semaine** |
| Être vu (apprendre) | Étoile sur un repo | Étoile sur une **lecture** |

GitHub **ne sort pas** un repo privé, ni un génie qui n’a jamais poussé en public. Nous non plus. Pas de note magique « il est trop fort, on le sort quand même ».

**Public par défaut.** Une prise atterrit sur la page. « Je n’ai pas partagé » = je n’ai pas envoyé le lien / pas fait challenger. La page existe. Le tableau, non. Le lien, c’est déjà sortir.

**Privé** (plus tard, si on le propose) : invisible à la page des autres, au tableau, aux étoiles. Comme un repo privé.

### Challenge — inchangé

Une lecture n’entre au **tableau semaine** que si **deux** gens ont essayé de la casser avec une pièce et n’y sont pas arrivés. Sans attaque, tu n’es pas premier par forfait. La phrase peut rester sur le deal ([jeu.md](jeu.md) §2) ; elle n’est **pas** au classement. C’est le PLG : pour monter, il faut que d’autres jouent.

### Étoile — apprendre, pas un like

L’étoile n’est pas une note. Ce n’est pas « ce sales est fort, 4,8/5 ». C’est : **cette lecture, je veux la retenir**. On apprend de la phrase + la pièce, pas d’un badge.

Geste : étoiler = **jouer ce cas contre sa phrase** (ou la garder pour le jouer). Comme un clone, pas un like vide. Le like vide, c’est du stuffing. Le clone, encore du PLG.

L’étoile fait monter en **découverte** (liste « à apprendre », lectures étoilées). Elle **n’écrit pas** le tableau d’équipe. Deux compteurs, comme GitHub : étoiles ≠ attaques.

## Encore ouvert (pas le test)

Intra / inter équipe, vendredi / mois : on classe des **lectures**, pas des têtes. Deux prises identiques = une lecture.

- **Vendredi (intra-équipe)** : arêtes — qui a cité contre quelle phrase. Dump dimanche soir morte lundi → **pas** dans le mois.
- **Fin de mois (inter)** : types d’erreur encore chauds, peaux différentes. Pas un cumul de quatre vendredis. Inter = lectures qui ont tenu **hors de ton métier**.

## Page `3xrep.com/<pseudo>`

URL qu’on envoie. Pas un transcript. Pas une scorecard.

| Zone | Public (le lien) | Intra-équipe | Inter-boîtes |
| --- | --- | --- | --- |
| Lectures | Cas + phrase + pièce. Même à 0 étoile, 0 challenge. | Idem + qui a attaqué | Lectures sur une peau **hors métier**, si elles ont tenu |
| Étoiles | Compteur sur la lecture ; geste = rejouer contre | Idem | Découverte, pas un palmarès de boîtes |
| Tableau semaine | Pas sur la page perso comme un rang | Phrases qui ont encaissé deux casses ratées | — |
| Semaine / mois (listes) | Deux listes, **pas un chiffre** | Arêtes de la semaine | Types, pas des noms |
| Interdit | 7/10, XP, palier, « rang 12 », moyenne, like sans jouer | Classement de personnes à points | Palmarès de boîtes à score |

Le pseudo est sur la page. Le **cas** porte le trou. On ne te note pas.

Copains / collègues : on envoie le lien. Pas un feed. Pas LinkedIn.

## Ce qu’on refuse (même plus tard)

Note sur le vocal. Elo / 7/10. Compteur de cas joués. Streaks comme produit. Dashboard « moyenne d’équipe ». Le modèle qui élit un gagnant. Ligues Duolingo. Un nombre à côté du pseudo qui dit « tu es bon ». Étoile = like sans rejouer.
