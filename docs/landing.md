# Landing — 3xrep.com

Figé. 1er septembre 2026, soir. Gagne sur le hero / la home. Le PRD §13 (page d’intention, pas un magazine) tient. [v0.md](v0.md) tient pour le slice produit (même porte MCP). Ici : ce que la page *dit* et à qui elle parle en premier.

## Hero

**Hire the best VP Sales agent for 99 €/month.**

*for the entire organization* — petit, italique, tout de suite sous. Ça tue la lecture « par siège ».

Pas de deuxième H1. Pas de « tu crées / on est le cerveau » en hero : c’est le manifeste, trop interne. « VP » = le choc (un VP à 99 €). « Agent » = pas un humain. Hero EN. On ne traduit pas VP Sales.

CTA : créer l’agent / payer. Pas de démo. Pas de Calendly.

## Preuve

Pas un dashboard. Un terminal / session **Cursor ou Claude Code** qui tourne : *Débriefe le call avec Julien.* → `audit_deal` → la [sortie](sortie.md).

Huit secondes, une boucle, un deal. Le motion *est* le mockup.

Craft Warp / Linear : noir, mono pour les faits, filet. Interdit : vert acide, glow, CRT, `>_` décoratif. [terrain/design.md](terrain/design.md) anti-AI look.

## Logos

Claude Code · Cursor · Codex. Cet ordre. Ceux du terminal.

Premier visiteur = founder déjà dans l’agent de code. Un AE qui ne sort pas de HubSpot n’est plus le premier écran. Assumé. Même SKU, même porte. Pas un troisième produit.

Écart à [v0.md](v0.md) § « Claude Code / Codex : bonus geek » : sur la *page*, ils sont le visage. Dans le *produit*, c’est toujours le même MCP.
