# Disclaimer — cas durs

Figé. 30 août 2026. Auteur : Édouard Tiem.

Pour que le terrain tienne : les cas sont **durs**. Pas un cran. Pas une variante facile.

## Texte (joueur)

Une fois. Court. Landing, mail. Pas un cours. Pas le beat 1.

> Les cas sont durs. En France le marché s’est durci dans beaucoup d’industries : plus de monde pour dire non, plus long à closer, plus de « on réfléchit ». Parfois le réel est plus facile. On joue les cas durs.

Pas d’autre paragraphe. Pas de stats. Pas de « tendance 2026 ».

## Pourquoi

Le marché FR B2B s’est durci dans beaucoup d’industries. Les prospects sont moins faciles à closer. Entraîner facile, puis rentrer lundi dans le dur = le produit ment.

Parfois lundi sera plus simple. Tant mieux. On n’écrit pas ces cas-là. On écrit le dur.

## Ce que « dur » veut dire

Les copies (point 2) **sont** le marché dur : l’ops ne t’offre pas le DAF, le DAF n’est pas chaud, « on réfléchit », le comité, l’inertie.

Ça ne veut pas dire : le deal est perdu d’avance. **Voir** reste possible. Le trou reste **le tien**. On le nomme.

## Ce que ce n’est pas

- Un cran facile / moyen / dur. Pas de variantes. [template-parcours.md](template-parcours.md) point 2 : copies.
- Une carte chance. Pas « le budget a sauté ». [cadrage.md](cadrage.md).
- « Le marché » à la place du trou. Si tu sors « c’est dur en ce moment » sans méthode, le produit a échoué.
- Un brief avant le beat 1. Le HUD c’est le deal. Le disclaimer n’explique pas le piège.
- Un article formation sur l’économie FR.
