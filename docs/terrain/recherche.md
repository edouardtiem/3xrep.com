# Recherche — pourquoi ce cadrage

Portée et tranchée le 30 août 2026. Cette note ne rouvre pas les décisions. Elle dit **pourquoi** elles tiennent.

## 1. Le trou que 3xrep vise

Un commercial B2B perd rarement « parce qu’il ne connaît pas le script ». Il perd parce que le dossier est vide et qu’il ne le voit pas.

Le DAF dit non. Le champion est gentil. Le CRM est au vert. Personne ne peut pointer **quelle case** manquait — métrique, buyer économique, critère, process, douleur, champion réel. MEDDIC / MEDDPICC le disent depuis trente ans : un deal qui cale a une lettre vide ; une case cochée sans preuve est une case vide ([Retorio](https://www.retorio.com/blog/meddic-sales-methodology), [Ziellab](https://ziellab.com/post/meddic-sales-qualification-b2b-revops-guide)).

Les formations (Simple Sales, Uptoo, kickoffs) ferment. Le lundi, le deal n’est plus le slide. 3xrep n’est pas un cours qu’on ferme. C’est un terrain : cas qui changent, on y revient.

## 2. Ce que le marché vend déjà — et ce qu’il ne vend pas

Trois familles, toutes à côté.

| Famille | Exemples | Ce qu’elles sont | Pourquoi ce n’est pas 3xrep |
| --- | --- | --- | --- |
| Roleplay IA / meeting | Hyperbound, Second Nature, Yoodli | Un faux appel. Audio ou avatar. Score de call. | Meeting dans le produit. Entreprise, devis, onboarding. On entraîne la **bouche**, pas le **dossier**. |
| Enablement / LMS | Mindtickle, Allego, Highspot | Contenus, certifs, coaching manager. | Cours qu’on ferme. Ops dédiés. Pas un mardi soir avec un collègue. |
| Mini-jeu / CYOA / QCM | Branching e-learning, « 2 min pour closer » | 3 choix, 1 bonne, chance ou script. | Rejeté. Voir §3. |

Aucune de ces familles ne te met devant un **tableau vide** et ne te force à **reconstruire le dossier dans le deal**. C’est le trou.

Hyperbound / Second Nature / Mindtickle se vendent en sales-led, prix caché, setup semaines à mois. 3xrep n’entre pas là. Pas d’appel. Un cas Google. Un mail qui **est** le cas.

## 3. Formats rejetés (Édouard)

### 2 min CYOA

Un arbre à 3 portes en deux minutes. Ça a l’air d’un jeu. Ça n’entraîne pas.

La recherche e-learning le dit : le branching « faux-linéaire » (une bonne réponse déguisée) est vu tout de suite ; le branching vrai coûte trop pour des cas qui doivent **changer** ; sans feedback « pourquoi », le joueur sort en « je ne sais pas ce qui s’est passé » ([eLearning Industry](https://elearningindustry.com/branching-scenario-method-linear-non-linear-branching-scenarios), [Learning Owl](https://learningowl.in/branching-scenarios-in-elearning-when-they-are-worth-the-investment-and-when-they-are-not/)).

Deux minutes, c’est le format pub. Pas le format deal. Un DAF qui dit non n’est pas un swipe.

### Mini-QCM

jesaisfaire a raison **pour l’embauche** : un QCM métier trie « sait faire / sait se vendre ». 3xrep n’embauche pas. Un QCM de vente te dit si tu as lu MEDDIC. Il ne te fait pas **sentir** la case vide au moment où le DAF coupe.

Le rattachement méthode **après** la case sentie, ce n’est pas ce QCM. C’est le nom du trou. [methodes.md](../methodes.md).

### Chance

Dé, carte chance, « le budget a sauté ». Ça excuse le trou. Le produit doit nommer le trou. La chance le noie.

### Points / ligues

L’aspect jeu reste (tension, gagné/perdu, rejouer le même deal autrement). Les ligues transforment le terrain en classement. On entraîne le classement, plus le dossier.

### Meeting dans le produit

Roleplay vocal, visio, avatar. C’est Hyperbound. Ça demande un créneau, un casque, souvent un manager. 3xrep se joue. Copains, collègues. Seul aussi. Pas de meeting.

### CPF

Ça transforme 3xrep en organisme. Qualiopi, dossiers, « heures ». Le test est : elles reviennent semaine 2. Pas : on a un agrément.

## 4. Les trois formats A / B / C — ce qui a été tranché

Travail Origin tmp. Décision : **A+B, une seule quête. C hors test.**

| | | Dans le test ? |
| --- | --- | --- |
| **A** | Reconstruire le dossier. Tableau vide → cases. Tu vois tes trous. | Oui, **dans** le deal |
| **B** | Le deal avance. L’objection arrive. Elle est la facture de A. Une action : poser un fait. | Oui, **même** quête |
| **C** | Vacation — autre pression (absence, relais, deal qui vit sans toi). | Non |

Séparer A et B (d’abord « remplir le dossier », ensuite « gérer l’objection ») refait un cours. Le DAF ne t’attend pas à la fin du module. A+B = une quête : tu construis **pendant** que ça brûle.

C est un vrai cas. Pas le premier. Hors test.

## 5. Durée ressentie ~15 min (12–25)

Assez long pour qu’un trou ait le temps de **coûter**.  
Assez court pour un mardi soir, sans créneau, sans manager.

Sous 10 min, on retombe dans le CYOA. Au-dessus de 25, c’est une session de formation. On a fermé ça.

## 6. Acquisition — cas précis, pas une marque

Personne ne cherche « terrain d’entraînement vente ». Les gens cherchent le **cas** :

- DAF dit non — `titre_google` du premier parcours (Call avec l’ops). Landing / mail. Pas le nom du cas à l’écran (le piège se découvre).
- champion gentil, zéro pouvoir — même famille, pas un deuxième parcours
- préparer sa prospection / cold call qui meurt — cas de parcours **futurs** (`debut` préparation ou prospection), pas le test 1
- deal au forecast, dossier vide — parcours possible, plus tard
- objection prix après une démo trop tôt — parcours possible, plus tard

Google = le cas. Le mail = le cas, deux minutes, jouable. Pas un Calendly. (Cohérent avec ce qui a déjà échoué côté Simple Sales : outils qui demandent au directeur de raconter un pipe, ou un Calendly avant d’avoir senti quelque chose.)

## 7. Kill switch : jesaisfaire

jesaisfaire existe, encaisse, a un premier test gratuit. Si 3xrep ne revient pas tout seul semaine 2, on n’empile pas un deuxième produit mort. On coupe.
