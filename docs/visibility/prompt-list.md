# Prompt list — seed, à valider

**Seed.** Pas figée. Personne n’a encore tourné ces lignes sur le web ni collé un paste ChatGPT/Claude. Ne pas citer cette liste comme une vérité d’acheteur. Éditer via le skill `build-3xrep-prompt-list`. Tourner via `ai-search-visibility`.

16 lignes (plafond 20). **5 top** marquées. Mots d’acheteur, pas jargon SEO. Landing EN → EN d’abord ; FR là où un acheteur mixte le dirait comme ça.

Cible du seed : inconnu qui cherche un **VP Sales agent**, du **sales enablement**, un **AI sales coach for the team**, une alternative à **Gong / Hyperbound / Second Nature**, ou qui décrit un **DAF / deal stuck / discovery**. Plus la marque **3xrep**.
