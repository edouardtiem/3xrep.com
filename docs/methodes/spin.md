## 1. Identité

Questionnement Rackham. Situation → Problem → Implication → Need-payoff. Ce qu’elle force : ne pas rester aux questions de situation (interrogatoire CRM). Ce que ce n’est pas : un script de quatre questions, ni MEDDIC.

Chevauchements : Implication + Need-payoff = Identify Pain + Metrics / coût de l’inaction. Problem = BEBEDC Besoin. Challenger (enseigner l’implication que le compte ne voit pas). Gap Selling (l’écart se creuse dans l’implication).

## 2. Parties

| Partie | Su | Supposé | Trou |
| --- | --- | --- | --- |
| **Situation** | Le minimum pour comprendre le contexte. | Tour d’horizon de 20 min. | Trop de situation = il s’ennuie, tu n’as pas de douleur. |
| **Problem** | Un problème **actuel**, dit par eux. | Notre problème à nous. | Sauté, on a pitché. |
| **Implication** | Ce que le problème **coûte** s’il reste (chaîne). 5 pourquoi. | « C’est chiant. » | Problem sans implication = regret. |
| **Need-payoff** | **Lui** dit la valeur de résoudre (ses mots). | Notre ROI. | Tu as dit le payoff à sa place. |

Phrase de trou : « SPIN : beaucoup de Situation, zéro Implication. Après “deux jours / mois”, tu as enchaîné rollout. »

## 3. Pourquoi

Les questions de situation rassurent le commercial. Elles ne font pas bouger un DAF. L’implication est là où le deal naît. Le need-payoff, dit par lui, est ce qu’il répétera au comité — sinon il répétera tes features.

Lundi : moins de recaps « contexte posé, bonne relation ».

## 4. Dans l’agent

Porteuse ou emprunt dès que le matériau est un call de découverte. L’agent classe les questions **réelles** du user dans les quatre seaux. Verdict : assez loin = Implication tenue ou consciemment trouée, Need-payoff dans sa bouche.

Sortie valide : « Il a ouvert le Problem (“deux jours”). Pas d’Implication (“et donc, en fin d’année, ça fait… ?”). Need-payoff dit par toi, pas par lui. »

Sortie interdite : « Pose une question S, P, I, N. »

## 5. Lundi

Relire le call : combien de S vs I. Si S >> I, le prochain call commence à I, pas à « on se remet dans le contexte ».

## 6. Lundi — CRM

Notes longues = souvent Situation. Un champ Need rempli par l’AE ≠ Need-payoff.

## 7. Lundi — ChatGPT, Cowork, Grok Bot

| Outil | Geste |
| --- | --- |
| ChatGPT | Lister les questions du commercial, les taguer S/P/I/N. |
| Claude Cowork | Une implication + un need-payoff à lui faire dire, pas à lui envoyer. |
| Grok Bot | Talk-ratio inverse : si tu as parlé 70 %, SPIN n’a pas eu lieu. |

## 8. pSEO

Queries : `SPIN selling`, `questions implication`, `need payoff`. CTA = agent sur le deal.
