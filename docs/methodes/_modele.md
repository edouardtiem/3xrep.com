# Modèle — une méthode dans le dur

Copier ce fichier vers `docs/methodes/<slug>.md`. Une méthode (ou une **partie** qui se Google) = un fichier. Pas un chapitre de cours.

Une écriture, trois usages plus tard :

| Usage | Quand |
| --- | --- |
| **Agent / spec** | Le [spec](../spec-agent.md) choisit et nomme. Ce fichier tient les parties. |
| **Tools MCP** | Plus tard : même fond, lookup déterministe. |
| **pSEO** | Page `3xrep.com/methodes/<slug>` — acquisition. **Après** le premier Connect. Pas un blog LMS. |

Si une section ci-dessous est vide, le fichier ne part pas. Surtout pas « lundi » ni « outils ».

## Front

```yaml
slug: meddic
```

## 1. Identité

Une phrase. Ce que ça force. Ce que ce n’est pas (pas un cours, pas la seule « bonne » grille).

Chevauchements obligatoires : quelles **autres** méthodes nomment la même case. Ex. Economic Buyer = BANT Authority = BEBEDC Décideurs.

## 2. Parties

Chaque lettre / levier / cran : nom, ce qui est **su** vs **supposé** vs **trou**, phrase de trou nommé.

## 3. Pourquoi (cadre — psy, humain, prod)

Pourquoi ça tue le deal si c’est vide. Psychologie de l’ops vs du DAF. Ce que ça change lundi (productivité : moins de forecast fantôme, moins d’appels au mauvais).

Pas une leçon avant le beat 1. C’est ce que le joueur **rencontre** au trou nommé.

## 4. Dans l’agent

- Quand le spec la prend (porteuse vs emprunt).
- Sortie valide (trou + méthode + partie, citation).
- Sortie interdite (XP, QCM « c’était quelle lettre ? », « sois plus MEDDIC »).

Archive terrain (mini-situations, beats) : seulement si ça aide le rattachement. Pas un parcours à implémenter.

## 5. Lundi — la vie de tous les jours

Pas le jeu. Le mardi matin.

- Où ça se voit **sans** 3xrep : pipe review, one-to-one, mail au champion, silence du DAF.
- Ce que tu fais concrètement (une action, pas un mindset).

## 6. Lundi — le CRM

Champs. Ce qu’une case verte **sans preuve** veut dire (vide). Exemples : HubSpot / Salesforce — `economic_buyer`, `metrics`, `next_step_with_eb`. Pas un tutoriel CRM. Le trou, dans l’outil qu’ils ont déjà.

## 7. Lundi — ChatGPT, Cowork, Grok Bot

**Dossier**, pas bouche. Pas de visio. Pas de roleplay vocal.

Pour chaque outil, **un geste** (pas un prompt novel) :

| Outil | Geste |
| --- | --- |
| ChatGPT (work) | Ex. : à partir du recap d’appel, lister les lettres vides + une question qui coûte. |
| Claude Cowork | Ex. : ouvrir le dossier compte (site, org, LinkedIn) et poser qui tranche, sans inventer. |
| Grok Bot | Ex. : challenger le forecast « on close vendredi » contre les cases vides. |

Si l’outil parle au client à ta place, on a cassé le cadrage.

## 8. pSEO (mémoire jusqu’aux pages)

Queries. Titre de page = la query, pas « 3xrep — formation MEDDIC ». CTA = **jouer le cas**, pas booker 15 min. Une page par `slug` (et par partie si la partie se cherche).
