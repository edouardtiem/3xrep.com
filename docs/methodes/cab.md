## 1. Identité

Caractéristique → Avantage → Bénéfice. Partir de l’offre. Le bénéfice est la dernière marche. Ce que ce n’est pas : « la mauvaise » méthode. Utile quand **lui** a demandé comment ça marche, ou en réponse à une question produit.

Chevauchements : BAC (l’inverse). CAP. Si tu fais CAB sans qu’il ait demandé la carac, tu pitches.

## 2. Parties

| Partie | Su | Supposé | Trou |
| --- | --- | --- | --- |
| **Caractéristique** | Un fait produit, demandé ou nécessaire. | Catalogue entier. | Feature dumping. |
| **Avantage** | Ce que ce fait change vs l’alternative. | « C’est mieux. » | Avantage non relié à *sa* douleur. |
| **Bénéfice** | Pour **lui**, dans son levier. | Value prop. | On s’est arrêté à l’avantage. |

Phrase de trou : « CAB non fini — tu as décrit le module, pas ce que Julien gagne le dimanche soir. »

## 3. Pourquoi

Sans la dernière marche, l’ops entend un outil, le DAF entend un coût. CAB n’est dangereux que quand on le prend pour tout le call.

## 4. Dans l’agent

L’agent nomme CAB quand le user est parti de l’offre. Il dit si c’était le bon départ (question produit) ou un raté (il avait ouvert une douleur).

Sortie valide : « Il a demandé “ça s’intègre où ?” — CAB légitime. Tu t’es arrêté à l’API, bénéfice non posé. »

Sortie interdite : « CAB c’est mal. »

## 5. Lundi

Si tu commences par le produit : force la phrase de bénéfice **avant** la slide suivante.

## 6. Lundi — CRM

Product playbooks = CAB par défaut. Le trou est dans le call, pas dans le champ.

## 7. Lundi — ChatGPT, Cowork, Grok Bot

| Outil | Geste |
| --- | --- |
| ChatGPT | Extraire les CAB incomplets (carac sans bénéfice). |
| Claude Cowork | Une carac → avantage → bénéfice **sur ce compte**. |
| Grok Bot | Compter les features dites vs les bénéfices tenus. |

## 8. pSEO

Queries : `méthode CAB`, `CAB vente`. CTA = agent sur le deal.
