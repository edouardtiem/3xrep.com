Le geste de lecture reste [debrief.md](debrief.md). Ici : ce qui fait **jeu**, et comment des commerciaux de métiers différents se comparent. Pas une note 7/10. Pas un QCM.

**Écart au cadrage** : [cadrage.md](cadrage.md) dit « le scoreboard n’existe pas » (points, ligues, XP). Ici on tient : **pas de note sur la prise**. Classement d’une autre nature + page publique : [ranking.md](ranking.md) (page ≠ tableau, étoile ≠ challenge ; pas le test).

## Interdit

Note sur le vocal / le texte. QCM. Une seule bonne lecture. Le modèle qui élit un gagnant. Points, XP, palier. Meeting / bot. Type d’erreur écrit dans le titre du cas (spoiler). Checklist « les huit lettres » à la sortie.

## 0. Dossier solide, plusieurs trous

Le cas **a l’air tenu** : CRM vert, mails, call, Slack. Pas un dossier troué à l’œil. Dedans, **plusieurs** choses clochent (mauvais étage, métrique absente, champion qui n’en est pas un, urgence théâtre…). Aucun tampon à l’écran.

Quatre minutes : tu sors **ce que tu as vu**, pas la liste complète. Le rattachement nomme les trous **de ta prise**, chacun avec une pièce et une méthode. Deux lecteurs, deux sous-ensembles : les deux tiennent si les pièces tiennent.

Semaine 2 / autre peau : au moins **un** type d’erreur en commun (celui du parcours). Les autres trous peuvent changer. On ne fabrique pas un QCM à N bonnes réponses.

Écrire les cas : le **premier** prend du temps (pièces, plusieurs trous, rien n’est spoiler). Le deuxième moins. Ensuite l’usine ([roadmap.md](roadmap.md) § générateur) — pas des cas faciles, une cadence qui accélère.

## 1. Même type d’erreur, dossiers différents

Dans Acme, Julien dit « pas de budget ». Le CRM est vert. Le trou : **ce n’est pas lui qui tranche**, ou **ce n’est pas le bon étage**.

Un recruteur entend la même phrase chez la chargée. Un BTP chez le chef de chantier. Les dossiers n’ont pas les mêmes produits ni les mêmes gens. Ils ont **le même type d’erreur** : une phrase qui a l’air d’une info, trop bas dans l’entreprise.

Étiquette **interne, auteurs seulement** (jamais à l’écran) : ce cas est du type *budget / décideur au mauvais étage*. Le joueur ne le voit pas.

Se comparer : pas « 8/10 contre 6/10 ». Toi tu as nommé le type d’erreur. L’autre a parlé du produit. Sur ce cas, tu as vu ce qu’il fallait. Ce n’est pas un classement de personnes. C’est **le même exercice, deux peaux**.

Semaine 2 : autre dossier, autre métier, **même type d’erreur**. Tu reviens pour le retrouver quand le vocabulaire a changé. Si le 2e cas n’est pas vraiment le même type, semaine 2 c’est un autre exercice.

**Test 1** : un cas, déjà plusieurs trous, l’air solide. Le 2e cas s’écrit avec **au moins** le même type d’erreur, autre peau. Pas de tampon sur le HUD.

## 2. Une phrase reste ; le suivant la casse avec une pièce

Après tes 4 min, une phrase reste sur le dossier. Exemple : *« Le trou, c’est que Julien n’est pas celui qui décide. Preuve : l’appel du 12, il dit on décide en interne. »*

Le joueur d’après lit le même dossier. Il ne « fait pas mieux en note ». Il cherche **dans les pièces** quelque chose que cette phrase n’explique pas. S’il a cette pièce, sa phrase remplace. S’il nomme **autre chose** et que la tienne tient encore, **les deux restent**. Deux lectures honnêtes peuvent tenir.

L’adversaire : **la phrase d’avant**. Pas un manager. Pas l’acheteur. L’horloge sert à parler, pas à noter. Si personne ne revient, la phrase disparaît.

Le modèle **ne décide pas** qui a gagné. Il colle la nouvelle pièce à côté de l’ancienne phrase. Trop souple : rien ne bouge. Trop dur : chaque mail tue la phrase.

**3x (règle possible, pas le test)** : une phrase ne « tient » que si deux gens ont essayé de la casser et n’y sont pas arrivés. Trois passages. Le cas porte le trou, pas un nom de personne.

**Test 1 (20)** : possible sans comptes. Un fichier sur le cas = la phrase du dernier. Cookie joueur. Pas un classement de noms.

## 3. Tu ne joues pas chez toi d’abord

Plus tard : tu vends du SaaS, 3xrep te donne d’abord un cas recrutement (même type d’erreur). Un recruteur reçoit le SaaS. Défi : sans le jargon de ton métier, tu vois encore le trou.

**Pas au test 1.** Google / mail promettent un cas qui ressemble à ton monde. Forcer l’autre métier au premier clic = rebond.

## Test des 20

Un cas. Timer. Dossier qui a l’air sûr. Pas de phrase live obligatoire. Pas de swap de métier. Le 2e cas (semaine 2) = même type d’erreur, autre peau. C’est la raison de revenir.
