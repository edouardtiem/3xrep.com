# 6 septembre 2026 — moteur sur exhibits

## Décision

Audit ChatGPT (repo, pas un test terrain) : le moteur reconnaissait des formes, pas des preuves. Édouard : une pièce n’est tenue que si le prospect l’a dite dans une source réelle **et** que le commercial a posé la question qui ferme. Un titre (directeur, C-level) est un prior, jamais une preuve. Une note d’AE est un fait de grade B : on demande le transcript (coller dans le chat, ou brancher un notetaker → CRM).

Langue : transparente. L’agent extrait dans la langue d’origine ; le serveur juge la structure et la citation, pas le français.

Entrée double : `exhibits` en priorité, blob encore accepté (jamais `su`).

## Écart

`preuve_valide` regex (DAF + signe, un montant en €) pouvait valider « Le DAF ne signe pas ». `corpus()` collait tout. C’est fermé.

## Suite

Cas réels (dossiers qu’Édouard n’a pas écrits) pour vérifier la règle, pas pour la trouver. Pas les langues du site, pas $129.
