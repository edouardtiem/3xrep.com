# 6 septembre 2026 — gaps, cycle, siphon

## Décision

Édouard : automation qui liste les gaps MCP vs la connaissance sales mondiale ; loop plus rare pour intégrer ; audit mensuel du cycle user ; comment se protéger du siphon ; quelle data lock-in.

Tranché dans [gaps.md](../gaps.md) :

- Scan = classer vers les **pièces**, pas empiler les sigles. B2B. B2C park.
- Intégrer = rare, admission à six cases, seulement si un deal / une query tient.
- Audit mensuel user = `pipe_review` + reco de process (question mandatory, étape gatée, réflexe). **Pas** un % de conversion.
- Siphon du lexique : on l’accepte. Le lock-in est le jugement sur **leur** pipe dans le temps.
- Data maintenant : leurs artefacts + le CRM qui prétend. Plus tard : mémoire de jugement, zéro contenu.

## Écart

[differentiel.md](../differentiel.md) : plus de méthodes n’est pas le différenciateur. On ne rouvre pas ça. Le scan sert à ne **pas** manquer une **pièce** (JOLT indecision, Decision Criteria déjà au kernel mais pas dans `PIECES`).
