# 23 septembre — accueil local et mémoire Markdown

Décision d’Édouard : démarrer sur ordinateur dans Claude Cowork ou ChatGPT Work. Après la connexion MCP, la personne envoie le premier message affiché sur le site. L’agent demande qui elle est, ce que vend l’entreprise et où tenir sa mémoire locale. Il crée des notes Markdown dans le dossier autorisé, puis aide à connecter CRM, courriels et calendrier. Aucun projet en nuage ne sert de mémoire de travail dans ce premier parcours.

Le connecteur MCP ne peut ni parler spontanément à la connexion ni écrire sur le disque de la personne. `start_onboarding` transmet donc le parcours à l’agent, et le premier message déclenche cet outil. Les fichiers sont écrits par les capacités locales de l’application, après autorisation. Le profil personnel reste local ; seul le contexte confirmé de l’entreprise est partagé avec 3xrep.

Édouard accepte une mise en production avant les essais complets dans les deux applications. Les tests du serveur, du site et de la compilation passent. Les points à observer sur les vrais postes restent : découverte de l’outil, questions posées, dossier choisi, fichiers créés puis relus, et connexions aux sources.
