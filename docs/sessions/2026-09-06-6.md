# 6 septembre 2026 — domain 404

## Décision

`3xrep.com` / `www` / `3xrep-com.vercel.app` renvoyaient le 404 plateforme Vercel (`x-vercel-error: NOT_FOUND`), pas la landing. Le `next build` prod listait bien `○ /`. Cause : le projet Vercel a `framework: null` (preset Other) — pas de routing Next.js à l’edge.

Fix : `vercel.json` force `"framework": "nextjs"`. Redeploy. Pas un trou de page dans le git.
