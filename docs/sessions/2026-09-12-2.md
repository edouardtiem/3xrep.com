# 12 septembre 2026 — 2. Canaux optionnels, notes, base de test

## Décision

Pan croissance (leurs utilisateurs, pas nous) : **tout canal est optionnel**. Téléphone, courriel, Aircall, transcription : aucun n’est un must. Le must du cerveau, sur *ce* dossier : les preuves qu’on a, le trou, est-ce normal, proposer de brancher la source. Eux branchent. Eux collent. Direction, pas ship.

Une note collée via l’assistant : **retour de l’utilisateur**. Pas un mot dit par le client. Pas une preuve « dite par eux ».

Base de test **chez nous** : schéma `test` dans le projet 3xrep (dix affaires fictives). Pas un fichier client. Pas un second projet. Les tables produit ne bougent pas.
