# 23 septembre — une seule entrée Beta

Décision : pendant la recherche des 20 premières équipes, une nouvelle organisation entre uniquement par la Beta. L’essai standard de 14 jours reste un droit historique pour les comptes existants, pas une offre publique parallèle. Si le programme ferme ou si les 20 places sont attribuées, le formulaire et la base refusent les nouvelles inscriptions.

Le programme consulté en base était ouvert jusqu’au 3 novembre, avec 0 place attribuée. La suite locale passe : 143 tests, compilation, analyse du code et recette avec inscriptions fermées. Les pages ont aussi été lues avec la configuration Beta ouverte, sans créer de compte. La migration de fermeture doit accompagner la mise en ligne ; aucune production n’a été modifiée ici.
